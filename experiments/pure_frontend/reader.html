Keyboard Shortcuts

  • OOpen PDF
  • A / DPrevious / Next page
  • W / SPrevious / Next sentence (while reading)
  • Q / EPause / Resume reading
  • VFocus voice selection
  • TFocus TTS engine selection
  • MEnter / Exit mark skip areas mode
  • ZToggle Smart Reading
  • HOpen / close this help

Shortcuts are ignored while typing in text fields, selects, or text areas.
