# VIVIDpdf

https://vividpdf.pages.dev
![QR Code](https://api.qrserver.com/v1/create-qr-code/?size=150x150&data=https%3A%2F%2Fgithub.com%2FNathan903%2FVIVIDpdf)

Do you find reading dIFfiCUlT? Tired of buggy PDF readers that stutter over every page, or asks for money you don't have? 

VIVIDpdf is a webapp that reads PDFs, tailored for academic text. You can configure the app exactly to your needs, for free. [*Free as in Freedom.*](https://www.gnu.org/philosophy/free-sw.en.html)

# Reporting Bugs
 
Your app didn't work for my PDF! 

Please go to [Issues](https://github.com/Nathan903/VIVIDpdf/issues) to report it. Include the PDF if you can so I can see what weird formatting broke the app.

# Getting started
```
npm install
npm run dev
```
